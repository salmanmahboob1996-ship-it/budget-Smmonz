History & backup

Your JSON file

On iPhone this opens the share sheet — choose Save to Files. iPhone never overwrites: if budget.json is already in the folder it saves the new one as "budget 2". Either delete the old file first, or don't worry about names — every save is time-stamped inside, the app reads any name, and loading tells you when that copy was saved.
Nothing is ever sent anywhere — the app has no server and makes no network calls. The file is the only copy that survives clearing Safari data or changing phone.
